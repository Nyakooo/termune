## 安装与启动

发布包覆盖 Windows、macOS 和 Linux 的 x86_64 与 ARM64。安装命令见 [项目首页](../README.md)。安装后重新打开终端，运行 `termune`。

脚本默认将程序安装到以下位置。找不到命令时，可以直接运行对应的文件。

| 系统 | 默认安装位置 |
| --- | --- |
| Linux 和 macOS | `~/.local/bin/termune` |
| Windows | `%LOCALAPPDATA%\Termune\bin\termune.exe` |

Linux 发布包使用 GNU libc，播放需要系统 ALSA 运行库。已安装的程序可通过 `termune update` 更新，手动下载入口见 [GitHub Releases](https://github.com/Nyakooo/termune/releases/latest)。

## 登录与连接

在 NAS 上启用 FN Connect，安装并初始化飞牛音乐，再创建一个音乐独立账号。启动 Termune 后输入 **FN ID、音乐用户名、音乐密码**。FN ID 用来查找 NAS，登录使用飞牛音乐里的账号。

登录页按 `Tab` 或 `Shift+Tab` 移动焦点，按空格勾选「下次自动登录」。也可以用鼠标操作或粘贴。密码输入时会隐藏。

### 自动登录

勾选「下次自动登录」并成功登录后，Termune 会把会话令牌存到系统凭据库。下次启动时，如果会话有效，就直接进入曲库。音乐密码仅在本次登录时使用。

| 系统 | 凭据库 |
| --- | --- |
| macOS | 钥匙串（Keychain）。弹窗请求访问 `termune.music-session` 时，使用 Mac 的登录钥匙串密码授权 |
| Windows | 凭据管理器（Credential Manager） |
| Linux | Secret Service，例如 GNOME Keyring 或支持 Secret Service 的 KWallet，需要可用的用户 D-Bus 会话 |

关闭自动登录时，先从 **设置 → 断开连接** 回到登录页，再取消勾选。会话失效后，输入音乐密码重新登录即可。

### 局域网与中继

Termune 每次连接时都会用 FN ID 探测线路，优先选择通过校验的局域网地址。顶栏显示实际连接方式，例如「局域网 · 192.168.1.42」或「FN Connect 中继」。

同一局域网内仍显示中继时，先确认 NAS 的局域网地址可达。自签名证书或证书与 IP 不匹配都会导致 HTTPS 直连失败。在可信网络中，可以通过 **设置 → 局域网 HTTP → 允许** 开启 HTTP 直连，重新连接后生效。该选项会保存。**HTTP 会明文传输凭据，仅用于可信局域网。**

也可以用 `termune --allow-lan-http` 临时允许。公网线路使用 HTTPS。Termune 的 FN Connect 支持范围见 [协议说明](FEINIU_API.md)。

## 曲库、搜索与歌单

| 操作 | 快捷键 |
| --- | --- |
| 选择条目 | `↑` / `↓` 或 `k` / `j`，也可使用鼠标。按 `Home` / `End` 跳到本页首尾 |
| 打开详情或播放歌曲 | `Enter` |
| 切换分类 | `Tab` / `Shift+Tab`，也可按 `1` 至 `6` 或 `Alt+1` 至 `Alt+6` 直接切换 |
| 调整分类顺序 | `Alt+←` / `Alt+→` 或 `Alt+H` / `Alt+L` |
| 翻页 | `←` / `→`、`h` / `l` 或 `PageUp` / `PageDown` |
| 刷新当前页 | `R` |
| 收藏或取消收藏 | 在曲库歌曲列表按 `F` |

数字键 `1` 至 `6` 依次对应专辑、歌手、风格、全部歌曲、收藏和歌单。调整显示顺序后，`Tab` 按新顺序切换。

按 `/` 打开空白搜索框，输入关键词后按 `Enter`。输入时可按 `Ctrl+U` 清空，或按 `Esc` 取消本次编辑并保留当前列表。在搜索结果页按 `Esc` 可返回曲库。

### 自建歌单

1. 选中歌曲，按 `A` 或点击「加入歌单」，然后选择目标歌单。也可以在弹窗里新建歌单并加入。
2. 切到「歌单」分类，按 `Enter` 打开歌单。
3. 在歌单列表用 `N` 新建、`C` 改名、`D` 删除。在歌单详情里按 `D` 可移除选中的歌曲。删除和移除都需要确认。

歌单按飞牛音乐账号保存在本机。同一首歌可以加入多个歌单。移除歌曲只影响当前歌单。

## 播放、音效与歌词

| 操作 | 快捷键 |
| --- | --- |
| 暂停或继续 | 空格 |
| 停止 | `S` |
| 上一首或下一首 | `[` / `]` |
| 快退或快进 5 秒 | `Ctrl+←` / `Ctrl+→` 或 `Ctrl+h` / `Ctrl+l` |
| 调节音量 | `-` 降低，`+` 或 `=` 提高，也可点击或拖动音量刻度 |
| 切换播放模式 | `O` 或点击播放器中的模式 |
| 切换音效 | `E` 正向、`Shift+E` 反向，也可点击音效标签 |

点击或拖动进度条，松开鼠标时跳转。歌曲时长未知或音频线路不支持 Range 时，进度跳转暂不可用。

常见可播放格式包括 MP3、FLAC、WAV、M4A（AAC-LC、ALAC）、Ogg Vorbis 和 Opus。

### 播放队列

队列来自开始播放时打开的列表，例如搜索结果、专辑或本地歌单。浏览其他列表时，当前队列继续播放。回到播放来源后，切歌会选中新曲目，需要时自动翻页。

| 模式 | 歌曲播完后 |
| --- | --- |
| 顺序播放 | 播放下一首。到达队列末尾后停止 |
| 列表循环 | 播放下一首。到达末尾后回到第一首 |
| 单曲循环 | 重播当前歌曲。仍可手动切歌 |
| 随机播放 | 从当前队列随机选歌。有其他歌曲时，避免连续播同一首 |

### 音效

预设包括原声、醇厚低音、现场、Livehouse、律动和空间 3D。切换立即作用于下一块输出音频，播放进度继续。预设会保存。参数和实现见 [音效研究](AUDIO_EFFECTS_RESEARCH.md)。

### 歌词

专业模式显示歌词。带时间戳的歌词会随播放进度高亮，双击可跳转到对应位置。纯文本歌词可以手动浏览。

用 `Alt+↑` / `Alt+↓` 或在歌词区滚动鼠标进入手动浏览。10 秒内没有继续滚动时，带时间戳的歌词恢复同步。按 `Alt+Home` 可以立即恢复。

## 界面与设置

按 `P` 打开设置，可调整布局、配色、语言、显示模式、记忆位置和局域网 HTTP。用 `↑` / `↓` 选项，`←` / `→` 修改，`Esc` 返回。按 `?` 查看快捷键。

登录页可点击「设置」，按 `F1` 查看帮助。曲库中按 `Q` 退出，输入或弹窗中可用 `Ctrl+C` 退出。

| 专业布局 | 歌词位置 |
| --- | --- |
| Airwave | 左侧播放器下方 |
| Operations | 右侧栏 |
| Tracker | 顶部播放器内 |
| Btop | 顶部播放器内，曲库和概览在下方 |

按 `M` 切换专业与极简模式。极简模式保留曲库与播放控制。终端至少需要 **36 × 20** 个字符，空间不足时专业模式会切换到紧凑布局。

### 记忆位置与配置

「记忆位置」默认开启。Termune 按账号保存当前分类、搜索结果或详情，以及页码和选中项。下次登录时尝试恢复。可以在 **设置 → 记忆位置** 关闭。

| 系统 | 配置文件默认位置 |
| --- | --- |
| Linux | `~/.config/termune/config.toml`。设置了 `XDG_CONFIG_HOME` 时使用对应目录 |
| macOS | `~/Library/Application Support/termune/config.toml` |
| Windows | `%APPDATA%\termune\config\config.toml` |

配置文件保存连接与界面偏好，自动登录令牌放在系统凭据库。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 安装后找不到 `termune` | 重新打开终端，或直接运行安装脚本输出的完整路径 |
| FN ID 正确但登录失败 | 检查 NAS 是否在线、飞牛音乐是否已初始化，并确认输入的是音乐独立账号 |
| FN Connect 要求额外安全码 | Termune 当前支持直接使用 FN ID 探测线路。要求额外安全码的中继线路暂不可用 |
| 同一局域网却显示中继 | 查看[局域网与中继](#局域网与中继)，优先检查直连地址与 HTTPS 证书 |
| 自动登录失败 | 先手动登录。若凭据库未解锁，解锁后再启用自动登录 |
| 无法拖动进度条 | 等待歌曲时长加载。若当前线路不支持 Range，可以继续播放 |
| 歌词没有同步 | 用 `Alt+Home` 恢复跟随。纯文本歌词只提供手动浏览 |
| 更新失败 | 关闭其他 Termune 实例，确认安装目录可写，再运行 `termune update` |

## 诊断与反馈

| 命令 | 用途 |
| --- | --- |
| `termune --version` | 查看已安装版本 |
| `termune --help` | 查看命令行参数 |
| `termune --login-only` | 检查地址发现、线路探测和账号登录 |
| `termune --diagnose` | 额外抽查曲库、搜索和媒体资源 |

诊断时需要手动输入音乐账号。详细检查范围见 [协议说明](FEINIU_API.md)。

反馈时附上 `termune --version`、操作系统、操作步骤和脱敏报错。播放问题可一并附上音频输出设备和触发场景。请勿附带密码、令牌、Cookie 或完整网络抓包。 [提交问题](https://github.com/Nyakooo/termune/issues/new)
