# Tunerift 对照与本轮完成度

对照本机 Tunerift 的 `ui.rs`：页头/页脚分工、Airwave 留白、Receiver 卡片、Operations 分栏、Tracker 密集列表、Btop 概览，以及完整配色角色。没有把功能可用等同于视觉完成，也不以任意百分比宣称已达到同等成熟度。

| 部分 | 当前证据与边界 |
| --- | --- |
| 认证、曲库、搜索、封面资源和 Range | 用户提供真实 NAS PASS 结果 |
| 自动登录 | 用户确认正常；保留系统凭据存储与身份验证 |
| 播放 | VLC + 本机 Range 桥，支持进度/seek、跨页队列和四种播放模式；本地真实 VLC 测试通过，真实 NAS 新路径待测 |
| 原界面 | 重复工具栏/状态/快捷键、配色角色不完整、布局信息分工不足 |
| 本轮界面 | 重做五种结构、完整主题、统一设置和帮助，移除旧键位 |
| 封面与歌词 | 封面按用户要求暂不展示；歌词解析时间轴，跟随真实进度，真实 NAS 新歌词流程待测 |
| 同步歌词 | 已实现 LRC 秒级跟随和定位；纯文本只能手动浏览 |

主界面只在页脚放常用键位提示；F1 展开全部操作，F2 管理所有外观与账户设置。播放按钮在播放器区域，曲库区域不再复制播放工具栏。弹窗接管输入和点击区域。

专业模式的歌词位置：

| 布局 | 歌词 | 曲库 |
| --- | --- | --- |
| Airwave | 左侧播放器下方 | 右侧 |
| Night Receiver | 顶部接收机面板 | 下方卡片网格 |
| Operations | 右侧媒体栏 | 左侧，播放控制在下方 |
| Tracker | 顶部紧凑媒体条 | 下方密集列表 |
| Btop | 顶部媒体面板 | 下方曲库及概览 |
| 窄屏专业模式 | 上方紧凑歌词区 | 下方 |
| 极简模式 | 不展示 | 曲库加紧凑播放控制 |

本轮使用 Ratatui TestBackend 导出五布局 × 五配色，检查实际渲染结果，测试素材明确标记。预览导出命令：

```sh
TERMUNE_UI_CAPTURE_DIR=/tmp/termune-ui cargo test --bin termune export_ui_previews -- --ignored
```

真实使用仍需检查终端字体、True Color、NAS 歌词内容与图片格式。当前已接入真实 VLC 进度、LRC 跟随与队列自动切歌；原生音频引擎仍未实现，新增接口与播放行为待真实 NAS 验证。
