# 飞牛连接与兼容性说明

[返回项目首页](../README.md) · [使用指南](USAGE.md)

本文介绍 Termune 当前版本如何连接飞牛 NAS 音乐服务、使用哪些服务能力，以及已知的兼容性边界。它是面向用户和集成开发者的当前行为说明，不是飞牛官方 API 规范。

## 连接流程

Termune 支持通过 FN ID 发现 NAS，也支持直接探测手动填写的地址。两种方式都使用飞牛音乐的独立账号认证。

1. **设备发现**：使用 FN ID 时，向 FN Connect 查询候选地址。手动地址直接进入探测。
2. **线路探测**：逐一检查候选地址，优先使用可用的局域网直连线路；无法直连时再使用可用的远程线路。
3. **音乐服务检查**：确认目标地址提供飞牛音乐服务。
4. **账号登录**：使用音乐独立账号登录，并验证返回的用户会话。
5. **曲库访问**：按需读取曲库、搜索结果和媒体资源。

FN ID 用于发现 NAS，不是音乐账号，也不能代替音乐账号密码。Termune 不要求用户提供飞牛主账号密码。

## 账号与会话

- 登录需要飞牛音乐中创建的音乐独立账号。
- 密码仅用于登录请求，不会写入普通配置文件。
- 开启「下次自动登录」后，会话凭据保存在操作系统的凭据存储中：macOS Keychain、Windows Credential Manager，或 Linux Secret Service。
- 自动登录时，FN ID 模式会重新发现设备并探测可用线路，手动连接则探测上次保存的 NAS 地址。连接后会验证已保存的会话。会话失效后需要重新输入音乐账号密码。
- 如果系统凭据存储不可用，Termune 不会将会话令牌明文写入配置文件作为替代。

## 当前使用的服务能力

Termune 通过飞牛音乐服务读取和操作以下内容：

| 能力 | 用途 |
| --- | --- |
| 设备发现 | 根据 FN ID 获取可用的 NAS 连接地址 |
| 用户认证 | 音乐账号登录、会话身份验证 |
| 曲库浏览 | 歌曲、专辑、歌手、风格及歌单列表 |
| 收藏 | 读取收藏列表、添加或取消收藏 |
| 歌单 | 读取歌单及其歌曲，并在客户端管理个人歌单 |
| 搜索 | 按关键词查找歌曲 |
| 歌词 | 获取歌曲歌词并解析时间标签 |
| 封面 | 读取曲库条目的封面资源 |
| 音频 | 获取歌曲媒体流，支持播放所需的分段读取 |

列表采用分页读取；媒体资源按需请求，不会在启动时下载整个曲库或整首音乐。

## 连接方式与网络要求

- **局域网直连**：设备发现结果中存在可达的局域网地址，且服务端证书和网络配置满足连接要求时使用。
- **远程连接**：局域网不可达时，尝试 FN Connect 提供且当前环境可用的远程线路。
- **局域网 HTTP**：FN ID 发现和手动连接共用「局域网 HTTP」开关，且仅允许符合条件的局域网 IP。HTTP 不加密，可能暴露账号凭据和会话信息，只应在可信的私人局域网中使用。
- **HTTPS**：远程连接使用 HTTPS；自签名证书、证书名称不匹配或网络拦截可能导致连接失败。

Termune 当前不承诺支持所有 FN Connect 线路类型、额外安全码验证方式或所有 NAS 固件版本。FN Connect 与飞牛音乐的接口属于服务实现的一部分，服务端升级可能改变其行为。

## 兼容性与诊断

连接结果可能受到以下因素影响：

- NAS 是否在线；
- 飞牛音乐是否安装并完成初始化；
- 音乐独立账号是否有效，以及账号是否有权访问对应曲库；
- 局域网隔离、防火墙、DNS、路由器和证书配置；
- 使用 FN ID 时，FN Connect 是否已启用，以及候选线路是否可达；
- 使用手动地址时，保存的 NAS 地址是否仍然可达；
- 飞牛 NAS / 飞牛音乐版本对相关接口的调整。

遇到问题时，先在 NAS 确认音乐服务和账号可正常使用，再运行：

```sh
termune --login-only
termune --diagnose
```

提交问题时请附上 Termune 版本、NAS / 飞牛音乐版本、操作系统、连接方式和脱敏诊断结果。请勿提交密码、会话令牌、Cookie、签名 URL 或完整网络抓包。

## 接口兼容声明

Termune 是独立开发的第三方客户端。它通过公开可访问的服务接口与飞牛音乐交互，但这些接口并不等同于稳定、公开承诺兼容的第三方开发者 API。Termune 会尽力适配已验证的服务行为，但无法保证飞牛服务端升级后所有功能持续可用。

本项目与飞牛官方没有隶属、合作或背书关系。
