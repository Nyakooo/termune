# 音效说明

[返回项目首页](../README.md) · [使用指南](USAGE.md)

Termune 内置音频解码、输出和实时音效处理。播放过程中可以切换预设、调整音量和跳转进度，不需要额外安装独立播放器或音频处理软件。

## 音频处理流程

当前播放链路由 Termune 自身完成：

1. 从飞牛音乐获取歌曲音频流。
2. 在本机解码音频数据，并根据输出设备需要转换声道和采样率。
3. 将 PCM 音频送入实时音效处理流程。
4. 通过系统默认音频设备输出。

解码、音效处理和设备输出均由应用集成的组件完成。不同操作系统、音频设备、采样率和耳机 / 音箱会影响最终听感。

## 内置预设

Termune 内置六种预设。

| 预设 | 设计方向 | 听感说明 |
| --- | --- | --- |
| 原声 | 保持原始立体声 | 不叠加额外音效处理，适合希望听到接近原始混音的场景 |
| 醇厚低音 | 加强低频与低频谐波 | 增加低频厚度，同时控制容易产生浑浊感的中低频 |
| Livehouse | 营造较开阔的现场感 | 保留原「现场」的空间反射和较长混响尾音 |
| 律动 | 面向说唱、电子和节奏型音乐 | 突出集中的底鼓和贝斯，用较慢的动态压缩保留鼓点起音 |
| 空间 3D | 营造明亮、宽阔的声场 | 根据自制扫频的开关录音拟合均衡、声道延时和动态增益 |
| 全景环绕 | 扩展左右声场 | 根据鲸云全景环绕的双声道开关录音拟合独立滤波和声道延时 |

空间 3D 和全景环绕均由 Termune 独立实现。空间 3D 参考酷狗 3D丽音的实测听感，使用 48 kHz 扫频和独立立体声样本验证，较高输入电平下与参考仍有差异。全景环绕使用一首歌的 48 kHz 双声道录音拟合，并用同一首歌中未参与拟合的片段验证。

## 切换与控制

- 按 `E` 切换到下一种音效。
- 按 `Shift+E` 切换到上一种音效。
- 点击播放栏中的音效名称或 `E ▾` 可打开菜单，当前预设带有 `✓`。空间不足时可用滚轮查看其余选项。
- 音量可通过 `-`、`+`、`=` 或播放器音量刻度调整。
- 播放中切换环绕预设时会短暂平滑过渡，播放进度继续。
- 当前音效预设会随应用设置保存。

### 从旧版本升级

旧配置中的「现场」和旧版「Livehouse」会迁移到当前的「Livehouse」，使用原「现场」的混响。旧版「空间 3D」和「澄澈环绕」会迁移到当前的「空间 3D」，使用原「澄澈环绕」的调音。

## 格式与输出

Termune 集成音频解码能力，常见格式包括 MP3、FLAC、WAV、M4A（AAC-LC、ALAC）、Ogg Vorbis 和 Opus。具体可播放性仍取决于文件编码方式、媒体流是否完整以及服务端是否正常提供数据。

音频通过当前操作系统的默认输出设备播放。若没有声音，请检查系统输出设备、音量、静音状态以及其他应用是否占用或切换了音频设备。

空间 3D 和全景环绕的空间效果适合立体声输出。单声道设备会保留音色处理，并关闭左右声道间的延时。

## 听感提示

- 预设效果与耳机、音箱、音量和个人听感有关，同一预设在不同设备上的表现可能不同。
- 建议先从较低音量开始试听，尤其是低音和空间效果。
- 如果希望比较预设差异，尽量保持音量一致，避免将更响误认为音质更好。
- 原声预设适合作为比较基准；如果不喜欢某种处理，随时切回原声即可。
